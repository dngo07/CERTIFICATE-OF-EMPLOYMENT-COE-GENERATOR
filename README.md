# CERTIFICATE-OF-EMPLOYMENT-COE-GENERATOR
A Google Apps Script tool that turns Certificate of Employment issuance into a 10-second task. Live employee lookup, two certificate variants, auto-numbered tracking, and a real-time dashboard showing everything issued — no manual drafting, no lost records. Built with AI-assisted coding.

The Problem
Every Certificate of Employment request used to mean the same tedious loop: pull up the employee's file, copy their details, paste them into a template, format it by hand, save it, log it somewhere (if anyone remembered to), and repeat — for every single request, every single time. Multiply that by dozens of requests a month, and what should be a quick administrative task quietly eats hours of staff time that could go toward actual HR work.
What I Built
A Google Apps Script web app that turns certificate issuance into a 10-second task. Start typing an employee's name, and a live searchable dropdown pulls their position, department, salary, and tenure straight from the HR masterlist — no manual lookup required. Choose between two certificate variants (with or without compensation details), and the system auto-fills a pre-formatted template, generates a sequentially numbered PDF, and saves it directly to a designated Drive folder. Every issuance is logged automatically — no more chasing down who requested what, when.
The Dashboard
Beyond generation, the tool includes a live dashboard: total certificates issued, a monthly breakdown, variant distribution, and a real-time feed of recent activity — so anyone can see the full picture of certificate activity at a glance, without digging through folders or asking around.
Built With
Google Apps Script (backend logic), HTML/CSS/JS (frontend interface), Google Sheets (data source and audit log), Google Docs API (template merging), Drive API (storage and export) — developed through AI-assisted coding.
The Result
What once took several minutes of manual drafting per certificate now takes about 10 seconds — with built-in accountability tracking that didn't exist before. Zero manual formatting, zero inconsistent wording, zero lost records.
